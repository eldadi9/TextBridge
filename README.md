## The Problem

Translating and transforming text across languages — especially Hebrew, English, and Arabic — requires switching between multiple tools. TextBridge provides a unified interface for text processing with AI-powered quality.

## What I Built

- Multilingual text translation and transformation
- OpenAI-powered text rewriting, summarization, and formatting
- Clean, responsive React UI with markdown rendering
- Server-side API routes in Next.js for secure key handling
- Deployable on Vercel

## Key Features

- Text translation (Hebrew ↔ English + other languages)
- AI rewriting: formal, casual, concise, expanded
- Markdown rendering for formatted output
- Copy-to-clipboard for processed text
- Mobile-responsive layout
